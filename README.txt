PREVIEW
Extract the ZIP and open index.html in a browser. Internet is needed for the Google Fonts.

GITHUB PAGES
1. Open your GitHub repository: nexshalystudio/essentialz-demo
2. Upload/replace index.html, style.css, script.js and README.txt in the repository root.
3. Commit the changes.
4. Open Settings > Pages.
5. Set Source to Deploy from a branch, Branch main, Folder /(root), then Save.
6. Wait a few minutes and open https://nexshalystudio.github.io/essentialz-demo/
